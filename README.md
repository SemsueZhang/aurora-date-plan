# CupidLink 💘

一份送给 TA 的邀约计划书，一键生成甜甜的约会清单。

CupidLink 是一个纯前端、无后端的约会计划小工具：按步骤填写时间段、想做的事、想吃的、出行范围和心情，最后点一下就能生成一段可爱的约会清单文本，复制后直接发给你的约会对象。

## ✨ 功能

- **分步向导**：时间段 → 做什么 → 吃什么 → 出行范围 → 心情，顶部圆点可随时跳转，支持「上一项 / 下一项」
- **丰富的预设选项**：14 种活动 + 14 种美食，均带 emoji 图标，支持多选
- **自定义选项**：输入文字后点「确定」或按回车即可添加
- **出行范围 & 见面地点**：本市 / 跨市出行，并可填写具体见面地点（带确认键）
- **我此刻的心情**：约会前、发出邀约时的心情
- **时间格式**：生成的时间显示为「月/日 时分」
- **随机甜甜结尾**：内置多句祝福文案，每次生成随机一句
- **一键复制**：复制清单直接粘贴发送
- **多语言**：简体中文 / 繁體中文 / English / 日本語 四语切换，选择保存在浏览器本地

## 🛠️ 本地运行

纯静态站点，无需安装任何依赖：

```bash
# 方式一：直接双击打开 index.html
# 方式二：启动本地静态服务器
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```
